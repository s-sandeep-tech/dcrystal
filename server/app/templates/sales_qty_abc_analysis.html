About this report

Sold Qty counts distinct invoice barcodes within each complete hierarchy path across the selected period; every null-barcode invoice row counts as one. Parent quantities sum their children. Repeated sales of the same barcode within a path count once; a barcode appearing in different paths counts in each path. This is a barcode-based quantity, not net transaction units.

Contribution uses the parent quantity; Overall Contribution uses the filtered report total. Siblings rank by quantity descending, then label and ID. Cumulative contribution restarts within each parent. A covers the first 80%, B the next 15%, and C the remainder. The row crossing a boundary stays in the category it completes. Zero-quantity rows are Unclassified.

Sold Weight includes invoice weights in kg. Net Turnover includes configured sales returns; MC Profit preserves source signs. Amounts display in Cr with full-value tooltips. Transaction filters apply to every metric; selecting only returns produces no sold quantity.

Search reveals matching paths without recalculating ABC. The footer always shows the complete filtered total, counting each leaf once.
